Advanced Setup
--------------

This section describes the steps to boot R-Car V4H SH with root file system stored on an NVMe SSD or on a USB storage device.

It also describes how specific device tree overlays are enabled automatically during boot, and how
to switch the board between the standard kernel and the real-time kernel.
