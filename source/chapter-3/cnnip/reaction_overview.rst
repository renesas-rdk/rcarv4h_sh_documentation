REACTION
^^^^^^^^

REACTION (Renesas Edge AI Compilation Toolchain Into Optimized Network) is a software framework
that enables developers to leverage the CNN-IP hardware accelerator on the R-Car V4H SoC for deep
learning inference tasks.

It provides a set of tools, libraries and Docker images to facilitate the deployment of
convolutional neural network models on the R-Car V4H SH hardware.

.. important::

   These pages give an overview of the flow only. The detailed guide is delivered with the SDK,
   in ``/opt/rcar-xos/v3.xx.0/docs/sw/hyco/user_manual``. Adjust the version in the path if a
   different SDK release is installed.

.. note::

   AI Agent skills are available at `REACTION AI Skills <https://github.com/renesas-rdk/reaction-ai-skills>`_
