System Configuration
====================

This chapter describes how to configure the system software of the R-Car V4H SH: rebuilding the Linux kernel, device tree and FIT image and deploying them to the board, using the peripheral interfaces from Ubuntu, and the Ubuntu Desktop and Docker features available on the board.
